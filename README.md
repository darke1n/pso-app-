# PSO App

A full-stack web application built with Python, featuring backend data analytics, database management, and an interactive web interface.

## Tech Stack
- **Backend:** Python (FastAPI / Uvicorn)
- **Database:** SQLite
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
